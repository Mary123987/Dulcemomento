# Dulce Momento

Sitio web de Dulce Momento, con catálogo, carrito y checkout de demostración.

## Ejecutar localmente

Requiere Node.js. Desde la raíz del repositorio:

```sh
cd dulce-momento
node server.mjs
```

Abre http://127.0.0.1:4173.

Consulta [la documentación del proyecto](dulce-momento/README.md) para editar el sitio y ejecutar sus verificaciones. Los informes y evidencias de SEO están en `outputs/`.

## Publicación

GitHub Actions publica automáticamente la demostración en https://mary123987.github.io/Dulcemomento/ al actualizar `main`. El checkout, los pagos y los formularios son simulaciones; no se reciben pedidos reales.
